# scripts/archive: разовые скрипты работы с данными

Здесь лежат 117 скриптов с датой в имени (`apply-*`, `fix-*`, `import-*`, `link-*`, `reparse-*`, `tz-*` и другие). Каждый один раз изменил или проверил данные
(загрузка отчёта и прайса, привязка документов, правки ТЗ и лотов, сверки) и остался как **история и средство отката**.

- **Не запускать повторно для новой работы.** Для новых операций пишется новый скрипт; запись данных всегда сначала в пробном режиме (без `--apply`).
- **Запуск как раньше**, только путь с `archive/`:
  `node --env-file=.env node_modules/.bin/tsx scripts/archive/<имя>.ts [--apply | --rollback]`
- **Журналы отката** лежат в `docs-inventory/corrections-journal-*.json` (папка вне Git, есть на рабочем столе в реестре `FUR_ERP` и в копиях `~/Backups`). Откат: тот же скрипт с `--rollback`.
- Внутри скриптов пути от каталога скрипта пересчитаны при переносе (`__dirname + "/.."`), поэтому корень проекта и `docs-inventory/` определяются как раньше.
- Постоянные инструменты (`backup.sh`, `mart-refresh.ts`, `mart-verify.ts`, `rebuild-demo.sh`, `gen-*`, `test-*`, `set-user-password.ts`) остались в `scripts/`.
