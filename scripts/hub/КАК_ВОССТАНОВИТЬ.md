# Как восстановить базу и файлы fur-erp

В этой папке лежат копии базы `fur_erp_<дата>_<время>.sql.gz` (последние 20, новые снимаются после ответов Claude не чаще раза в 30 минут; одинаковые не дублируются). Ещё 30 копий лежат в `все_автокопии_Backups` (это `~/Backups/fur-erp`).

Загруженные файлы (документы закупок, фото примерок) лежат в `../03_ЗАГРУЖЕННЫЕ_ФАЙЛЫ/uploads_<дата>.tar.gz`.

## Вернуть базу из копии

1. Запустите Docker Desktop (значок кита в Программах) и дождитесь, когда он станет зелёным.
2. Откройте программу **Терминал** (Программы → Утилиты → Терминал).
3. Вставьте команду, заменив имя файла на нужную копию, и нажмите Enter:

   ```bash
   cd ~/Projects/fur-erp && docker compose up -d db && sleep 5
   ```

4. **Внимание: следующая команда заменит текущую базу.** Сначала нажмите `СОХРАНИТЬ_СЕЙЧАС.command`, чтобы текущая база тоже осталась в копии. Затем:

   ```bash
   docker exec -i fur-erp-db-1 psql -U fur_erp -d postgres -c "DROP DATABASE fur_erp WITH (FORCE);" -c "CREATE DATABASE fur_erp OWNER fur_erp;"
   gunzip -c ~/Desktop/FUR_ERP/02_БАЗА_ДАННЫХ/fur_erp_ДАТА_ВРЕМЯ.sql.gz | docker exec -i fur-erp-db-1 psql -U fur_erp -d fur_erp
   ```

5. Запустите `ЗАПУСТИТЬ.command` и войдите.

## Вернуть загруженные файлы

```bash
mkdir -p ~/Projects/fur-erp/uploads && tar -xzf ~/Desktop/FUR_ERP/03_ЗАГРУЖЕННЫЕ_ФАЙЛЫ/uploads_ДАТА_ВРЕМЯ.tar.gz -C ~/Projects/fur-erp/uploads
```
