# Полная копия кода

`fur-erp.bundle` — весь репозиторий одним файлом: все ветки, вся история изменений, отложенные правки (stash). Обновляется сам, когда в коде появляется новый коммит.

Основная копия кода — GitHub: https://github.com/PetrFedin/fur-erp (приватный). Этот файл нужен, если пропадёт доступ к GitHub или к Mac.

## Развернуть код из этого файла на любом Mac

```bash
git clone ~/Desktop/FUR_ERP/11_ПОЛНАЯ_КОПИЯ_КОДА/fur-erp.bundle ~/Projects/fur-erp-restored
```

Дальше:

1. Скопируйте настройки: `cp ~/Desktop/FUR_ERP/10_НАСТРОЙКИ_CLAUDE/env_копия_настроек.txt ~/Projects/fur-erp-restored/.env`.
2. Верните выгрузки: `rsync -a ~/Desktop/FUR_ERP/05_ИСХОДНЫЕ_ДАННЫЕ/docs-inventory/ ~/Projects/fur-erp-restored/docs-inventory/`.
3. Верните базу и файлы по инструкции `02_БАЗА_ДАННЫХ/КАК_ВОССТАНОВИТЬ.md`.
4. Перенаправьте ярлык `01_КОД_ПРОЕКТА` на новую папку: `ln -sfn ~/Projects/fur-erp-restored ~/Desktop/FUR_ERP/01_КОД_ПРОЕКТА`.
