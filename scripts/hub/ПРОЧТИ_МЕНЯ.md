# FUR_ERP — реестр проекта THE FUR (МехУчёт)

Здесь собрано всё по проекту: код, база, загруженные файлы, документы, исходные данные, история всех запросов и изменений, подключения, настройки Claude. Папка обновляется **сама после каждого ответа Claude**. Чтобы обновить её вручную, нажмите `СОХРАНИТЬ_СЕЙЧАС.command`.

Текущее состояние (что сохранено, когда, есть ли неотправленное): `00_СОСТОЯНИЕ.md`.

## Что где лежит

| Папка / файл | Что внутри |
|---|---|
| `ЗАПУСТИТЬ.command` | двойной щелчок запускает проект и открывает его в браузере (http://localhost:3200) |
| `СОХРАНИТЬ_СЕЙЧАС.command` | двойной щелчок: свежая копия базы и файлов, обновление реестра, сохранение кода в GitHub |
| `00_СОСТОЯНИЕ.md` | сводка: последняя копия базы, последний коммит, отправлено ли в GitHub |
| `01_КОД_ПРОЕКТА` | ярлык на рабочую папку кода `~/Projects/fur-erp`. **Все правки делаются здесь**, отсюда идёт запуск |
| `02_БАЗА_ДАННЫХ` | копии базы и инструкция восстановления |
| `03_ЗАГРУЖЕННЫЕ_ФАЙЛЫ` | архивы загруженных документов закупок и фото |
| `04_ДОКУМЕНТАЦИЯ` | README, описание продукта, правила, все документы `docs/` (копия для чтения) |
| `05_ИСХОДНЫЕ_ДАННЫЕ` | Excel-выгрузки и `docs-inventory`: выгрузки из Google Drive «мех», журналы исправлений данных, сверки |
| `06_ЖУРНАЛ_ИЗМЕНЕНИЙ` | все изменения кода по датам, ветки, несохранённые правки (если есть) |
| `07_ЖУРНАЛ_ЗАПРОСОВ` | все ваши запросы Claude по проекту, по сессиям и по времени (`ВСЕ_СЕССИИ.md` — оглавление) |
| `08_ПОДКЛЮЧЕНИЯ_И_ДОСТУПЫ.md` | GitHub, Render, база, Google Drive, логины: где что и как попасть |
| `09_ПАМЯТЬ_CLAUDE` | заметки Claude о проекте: правила, решения, ловушки |
| `10_НАСТРОЙКИ_CLAUDE` | настройки запуска, хуки, копия `.env` (закрытая) |
| `11_ПОЛНАЯ_КОПИЯ_КОДА` | весь репозиторий одним файлом со всеми ветками и историей |
| `99_АРХИВ` | старые копии и спасённые папки (только для справки, не запускать) |

## Почему код — ярлык, а не папка на столе

Рабочий стол синхронизируется с iCloud. 08.10.2026 iCloud выгрузил тысячи файлов проекта в облако, и запуск и сборка зависали. Поэтому код лежит в `~/Projects/fur-erp`, вне iCloud, а здесь на него ярлык: открываете `01_КОД_ПРОЕКТА` и попадаете прямо в код. Всё остальное (копии базы, документы, журналы) лежит в этой папке по-настоящему и через iCloud дополнительно хранится в облаке.

## Если Claude недоступен

1. **Запустить проект:** двойной щелчок по `ЗАПУСТИТЬ.command`. Если macOS скажет «не удаётся проверить разработчика», нажмите на файл правой кнопкой → **Открыть** → **Открыть**. Нужен установленный Docker Desktop и Node.js.
2. **Сохранить всё:** двойной щелчок по `СОХРАНИТЬ_СЕЙЧАС.command`, на вопрос про GitHub ответьте `y` и нажмите Enter.
3. **Продолжить разработку с другим помощником или программистом:** дайте ему этот файл, `08_ПОДКЛЮЧЕНИЯ_И_ДОСТУПЫ.md`, `04_ДОКУМЕНТАЦИЯ/README.md` и доступ к GitHub. Правила проекта описаны в `04_ДОКУМЕНТАЦИЯ/AGENTS.md` и `09_ПАМЯТЬ_CLAUDE`.
4. **Восстановить на новом Mac:** `11_ПОЛНАЯ_КОПИЯ_КОДА/КАК_ВОССТАНОВИТЬ_КОД.md`, затем `02_БАЗА_ДАННЫХ/КАК_ВОССТАНОВИТЬ.md`.

## Правила, чтобы ничего не терялось

- Работать с Claude по проекту лучше в сессии, открытой в папке `~/Projects/fur-erp`. Тогда после каждого ответа срабатывают проверки и обновление реестра. Из папки `~/Documents/claude` реестр тоже обновляется.
- Код после каждой доработки сохраняется в GitHub (правило проекта: коммит и push в main).
- Ничего не удалять из `99_АРХИВ` и копий без проверки, что это есть в свежих копиях.
