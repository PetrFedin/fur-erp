## 4. Рекомендованный дизайн: (а) + (б), вариант (в) отложить
- **(а) «Сканер» по запросу** (S): агент снимает листинг Drive, считает diff с БД, пишет `sync-proposals-<дата>.md/json`. Нужен, потому что содержимое xlsx/pdf/msg читает только агент.
- **(б) Страница «Синхронизация»** (M–L): загрузка `manifest.json`, детерминированный diff, очередь решений, история. Новые таблицы `SyncRun`, `SyncFinding`; в `DriveDocument` добавить `modifiedTime`, `md5/size`, `lastSeenAt`, `missingSince`; журнал — `AuditLog(source=sync:<id>)`.
- **(в) Drive API с сервисным аккаунтом** (L): секреты, риск утечки, собственный парсинг; не снимает главную ручную часть (разбор документов в числа). Отложить.
- **Жизненный цикл партии/аукциона:** папка появилась → классификация по имени и пути → авто-привязка файлов → разбор агентом → предложения → подтверждение человеком → запись через существующие server actions → пересчёт и инварианты → «закрыто» (документы по doc-coverage есть, инварианты зелёные, платежи подтверждены, открытых находок нет).
- **Автоприменять можно:** создание `DriveDocument` по однозначному номеру, пометка дублей, обновление `drivePath/fileId`, `missingSince`, `docDate/docNumber/year` из имени.
- **Только предложением:** суммы, цены, количества, НДС, закупки, лоты, ТЗ, платежи, `confirmed/verifiedAt`, приёмка и завершение, даты и сезоны, цены моделей, удаление документов.
- **UI:** «Синхронизация: последний скан …, новых N, изменённых M, пропавших, ждёт решения K».

## 5. Карта формул: дубли и тесты
- Стоимость закупки: `lib/purchase-totals.ts`; `grossUp` скопирован локально в 5 местах (`purchases/actions.ts` ×2, `lots/auction-view.tsx`, `lib/purchase-summary.ts`, `purchases/[id]/page.tsx`).
- Себестоимость лота: `receivePurchase` → `lib/stock.ts`.
- Себестоимость ТЗ считается в 4 местах: `completeProductionOrder`, `syncCompletedOrderCost`, `batch-stats.orderStat`, `production/[id]/page.tsx` (плюс `analytics-orders`).
- Надбавка 4%: две формулы (`price4` — от цены без НДС; `extraInclOnly` — `totalCost×4%`); `COMMISSION_RATE` читается напрямую в 8 местах.
- «Процент от суммы» оплаты — 3 копии (`payments/actions.ts`, `payments/mark-actions.ts`, `production/mark-actions.ts`).
- Маркап — 3 выражения (`articles/page.tsx`, `production/[id]/page.tsx`, `analytics-pricing.ts`).
- Деньги в коде: `INVOICES_FOR_DRAFTS` в `supplier-debt.ts` (суммы счетов Веллмех на черновики).
- Остальное: долг — `lib/supplier-debt.ts`; оплата аукциона — `lib/auction-payments.ts`; партия — `lib/batch-stats.ts`; наценка и рекомендованная цена — `lib/analytics-pricing.ts`; НДС по ТЗ — `lib/tz-vat.ts`; молоток — `lib/lot-hammer.ts`; средневзвешенные — `lib/weighted.ts`.
