# Редактируемость: что можно править (08.10.2026)

Паттерн правки везде один: «Изменить» → окно (`src/components/edit-dialog.tsx`) → «Сохранить» / «Отмена». Введённое не пропадает при ошибке, версия записи `_v` защищает от чужой правки (`src/lib/concurrency.ts`), правка сбрасывает подтверждение (`resetVerification`), сервер ревалидирует страницы, журнал пишется расширением Prisma. Проверка: `scripts/test-editability.ts` (настоящие server actions на scratch-базе, ~75 проверок).

| Сущность | Было | Стало |
|---|---|---|
| Закупка, шапка (черновик) | счёт, УПД, дата, аукцион из справочника, поставщик, склад, валюта | без изменений |
| Закупка, шапка (принята) | не правилась вообще | правятся дата, № счёта, УПД, аукцион; поставщик, склад, валюта, курс заблокированы (лоты посчитаны); смена аукциона блокируется, если есть оплаты «аукциона целиком» |
| Позиции, лот в позиции | правка есть (после приёмки: цвет/сорт/лот; количество/цена пока лот не списан, не пул) | то же; размер лота (sizeGrade) пересчитывается при смене сорта |
| Лот (карточка лота) | править нельзя | «Изменить лот»: номер, сорт, размер, цвет из справочника, примечание; количество, цена, остаток не затрагиваются |
| Расходы закупки | только добавить/удалить | «Изменить» (до приёмки); после приёмки запрещено с объяснением (расход уже в лотах) |
| Оплата закупки | только добавить/удалить | «Изменить»: сумма, дата, способ, статус (оплачена/запланирована), п/п, заметка, перенос на другую закупку того же поставщика; проверка переплаты |
| Оплата аукциона/аванс | правка есть | без изменений |
| Оплата производства | только добавить/удалить | «Изменить»: сумма, тип, способ, дата, п/п, заметка, набор покрываемых ТЗ |
| ТЗ | форма правки всех полей есть | + «Изменить цвета»: несколько цветов с количеством и размерами (ProductionOrderColor) |
| Партия | номер/год не правились | «Изменить партию»: номер (свободный), название, год, план, примечание |
| Документы Drive/загруженные | открыть, скачать, заменить файл, убрать, загрузить | + «Изменить»: название, тип, номер, дата, примечание; загрузка до 10 файлов за раз, тип по имени файла; HEIC — понятное сообщение |
| Документы закупки (PurchaseDocument) | замена, метаданные, удаление есть | тип по имени файла, HEIC-сообщение |
| Справочники (аукционы, цвета, мех, артикулы, категории, поставщики, заказчики, материалы, склады) | править можно | без изменений |
| Пользователь | роль, активность | + имя |
| Сезон | название и даты | + код (уникальный) |
| Расходы закупки в журнале | не писались | добавлены в журнал |

## Намеренно запрещено
- Количество/цена/НДС принятой позиции при списанном лоте или пуле подкладки — сломало бы себестоимость ТЗ (было и остаётся, текст объясняет, в каких ТЗ лот).
- Расходы принятой закупки и валюта/поставщик/склад — уже зашиты в стоимость лотов.
- Смена аукциона принятой закупки при оплатах «целиком» — расчёты разошлись бы.
- Номер партии — только свободный; ТЗ — минимум одно покрываемое ТЗ у оплаты работы; сумма цветов не больше плана ТЗ.

## Не сделано / ограничения
- Перепривязка уже загруженного документа к другому объекту (закупка → оплата) — убрать и загрузить заново.
- Завершить/вернуть ТЗ в работу не добавлено (завершение создаёт движения готовой продукции) — отдельная задача.
- Доля оплаты по ТЗ: в схеме нет суммы по ТЗ (только связь), схему не меняли.
- Склады скрыты из меню, правка формой остаётся.
