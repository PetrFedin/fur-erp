## 2. Определения (логика владельца)

- Товар сезона: заказано / получено / продано / остаток по этому сезону.
- SSN (товар сезона): продажи товара этого сезона. Календарный сезон = SSN + олды.
- SO STD = продано товара сезона ÷ заказано. Закрытые сезоны: заказано = получено. FW26/27: заказано = подтверждение по отчёту, но не меньше полученного.
- SO AS = SSN, проданный в собственном календарном сезоне, ÷ заказано.
- «Остаток всего» = весь остаток на сегодня; «Остаток сезона» = получено − продано товара сезона.
- Источник истины: отчёт `sales-report-sizes:2026-11-02` (ReportSizeRow, seas{SS26, FW25/26, FW26/27}: conf, deliv, soldAll/Old/Ssn, rubAll/Old/Ssn, disc*).
