# Словарь терминов (подписи на экранах)

Только то, что видит пользователь. Ключи в коде, имена полей БД и названия документов («Спец. №13», «УПД №181») не меняются.

| Термин | Как показываем | Что значит |
|---|---|---|
| Итог по таблице | **Всего, ₽** (`TotalLabel`) | Сумма строк таблицы. Единица после запятой: ₽, шт., м, ₽/шт. |
| Итог по всей закупке меха | **Вся закупка** | Первый источник виджета «Мех» (бывшие «Все виды меха»/«Тотал»); внутри — слайды по типам меха («Все типы» → Лиса → …). Источники: «Вся закупка», «На аукционах», «У поставщика». |
| Итог по производству | **Всего** | Первый слайд плиток «В выпуске» / «Полная себестоимость (с работой)»; включает ремонт, группы «Одежда» и «Аксессуары» дают срезы. |
| Остаток на складе | **остаток на складе** | Что куплено и ещё не списано в ТЗ (бывшее «сток»). |
| Отклонение (Var) | **Отклонение** | Бюджет к текущим ценам системы, %: красный — выше на 15%+. |
| Наценка (маркап) | **Наценка** | Цена ÷ себестоимость; в средних — взвешено по выпуску. Рядом всегда база: «Изделия» и карточка артикула — от полной себестоимости (с работой) по всем ТЗ; «Аналитика → Цены» — от себестоимости сырья (без работы) по завершённым ТЗ (переключатель «База наценки»). Поэтому у одного артикула числа разные (M002: ×4,85 и ×5,67). |
| Спецификация | **спецификация** | Приложение к договору с поставщиком. В названиях документов остаётся «Спец. №13». |
| 4% | **4%** с «i»: надбавка 4% к сырью | Наценка 4% при купле-продаже меха и подкладки подрядчику (не комиссия Веллмеха; вознаграждение Веллмеха 4,5% за сопровождение закупки сырья — отдельно, в расходах закупки): +4% к цене меха и подкладки в ТЗ. К закупкам, оплатам и долгу не применяется. |
| Долг | **Долг**, **К оплате**, **Остаток** | Сумма минус оплачено, положительная. |
| Переплата | **Переплата N ₽** | Оплачено больше, чем стоит: отрицательный долг показывается положительным числом с этой подписью. Расчёт не меняется. |
| Номер ТЗ | **ТЗ 167**, позиции — **ТЗ 167 · поз. 2/3** | Рабочий номер заказа (`workOrderNumber`), без знака «№». Внутренний «П-2026-0129» — только в «i» / title; поиск работает по обоим номерам. |
| Внутренний номер ТЗ | **П-2026-0129** | Служебный уникальный номер позиции заказа; у нескольких позиций одного ТЗ рабочий номер общий. |
| Лоты в сводках | **5 лот.** (неразрывный пробел) | Число лотов в строке или плитке. |
| Лот | **Лот 70101** / карточка лота | Партия шкур или ткани с номером аукциона. Номер в таблицах — ссылка на карточку лота. |
| Вид меха | **Вид меха: Соболь** | Справочник видов; название вида в таблицах ведёт на страницу вида. |
| Партия (аукцион) | **SAGA 03.26** | Группа закупок одного аукциона; оплаты ведутся по партии целиком. |
| Куплено / Использовано / Остаток | **Куплено**, **Использовано**, **Остаток** | Куплено = Использовано + Остаток (без 4%). |
| С НДС / без НДС | **с НДС**, **без НДС** | Режим цен из шапки сайта. Рубль в числе один раз: «583 233 535 ₽», не «₽ ₽». |
| Оплачено | **Оплачено** | Сумма подтверждённых и неподтверждённых оплат без чужих переплат. |
| Журнал изменений | **История** | Расшифровка «поле: было → стало»; для составных и неизвестных полей — «изменено: поле», полное значение в «Подробнее». |
| Название вкладки | **<страница> — THE FUR** | Шаблон в корневом layout; у карточек в названии есть имя записи («Закупка З-2026-0049», «ТЗ 167»). |
| Работа | **Работа подрядчику** | Расход на пошив (Веллмех). Долг — «Долг по работе подрядчику». «К оплате всего» = за мех и подкладку + за работу подрядчику. |
| Три статуса подтверждения | **подтверждено документом**, **согласовано письмом**, **не подтверждено** | Один набор слов для оплат, счетов, сверки. «Подтвердить с расхождением…» остаётся. В кнопках решений владельца нет приставки «Решено:». |
| Процент надёжности | **подтверждено документами, % по сумме** | Главное число. Остальные называются иначе: «документы привязаны: N из M» (обязательные документы на карточках) и «строк подтверждено: N из M» (проверенные записи). Фраза «как связаны три числа» — `src/lib/reliability-note.ts`. |
| Остаток меньше 1 ₽ | **—** / **оплачено** | Копейки округления — не долг и не переплата. Две строки «Округление» в таблице закупок — одна «Округление N ₽». |
| Средняя цена шкуры | **₽ за шкуру** | В «Куплено» — вся сумма ÷ все шкуры; в «Из чего складывается стоимость меха» — только деньги лотов с количеством (разница в «i»). |
| Сводка по годам | вкладка в конце ряда «Сырьё» | Не удалена: мелкая вкладка справа, открывается по клику; те же таблицы, что на Главной. |
| Себестоимость сырья | **Себестоимость сырья (с 4 %)** | Мех (+ шкуры подрядчика) + подкладка + 4 % (режим «С 4%») + расходы ТЗ, БЕЗ работы подрядчика. Таблица партий, карточка партии (колонка), печать партии, «Аналитика → Изделия», «Аналитика → Цены». Голого слова «Себестоимость» без уточнения нет. |
| Полная себестоимость | **Полная себестоимость (с работой)** | Себестоимость сырья + работа подрядчика. Список ТЗ, карточка ТЗ, дерево «Партии → ТЗ → состав», плитка «Производство» на Главной, «Изделия», средние. Полная − сырья = работа. |
| В выпуске | **В выпуске**, в «i»: готово + в работе | Все ТЗ без отменённых и без ремонта: готово (завершённые ТЗ, 596) + в работе (план ТЗ «В работе» и «Запланировано», 108) = 704. Раньше называлось «Произведено». «Готово» (в аналитике раньше «Сделано») — только завершённые. Календарь в режиме «Стадии»: «Всего с ремонтом» 711 = 704 в выпуске + 7 ремонт. |
| Работа и доп. расходы | **Работа и доп. расходы** (столбец деревьев) | Работа подрядчика (63 743 182 ₽, как в плитках и оплатах) + доп. расходы ТЗ (фурнитура, прочее: 792 ₽ по ТЗ 178). Итог столбца 63 743 974 ₽ больше плитки «Работа» ровно на доп. расходы; подрядчику оплачивается только работа. |
| Лот и позиция | **лотов 279, позиций заказано 100** | Лот — партия сырья, уже полученная на склад; позиция — строка заказа без лота (заказано, не получено). 379 в «Закупках» = 279 + 100; 297 — все полученные лоты (мех и подкладка) в «Качестве данных». |
| ТЗ и позиции | **14 ТЗ · 16 позиций** | ТЗ — уникальный номер из документа; позиция — запись (артикул) в ТЗ. Везде «N ТЗ · M позиций» (`tzCountText`). |
| К оплате по меху | **К оплате** (закупки) | В «Закупки — итоги» переплата по подкладке не вычитается (подпись на плитке); на Главной она вычтена — поэтому 9 574 182 и 9 518 588 ₽. |
| Куплено у поставщика | **Куплено (закупки этого поставщика)** | Карточка поставщика — без шкур подрядчика; «Оплаты → За сырьё» и Главная добавляют шкуры подрядчика и к «Куплено», и к «Оплачено». |
| Ждут документа или проверки | **Ждут документа или проверки** | Оплаты с суммой больше 0 (`isCountedPayment`): и в реестре оплат, и в «Подтвердить → Платежи». Оплата на 0 ₽ не считается. |
| Лоты в шапке «Из чего складывается стоимость» | **лотов 295, позиций заказано 100, шкуры подрядчика без лотов** | Одна функция `lotCounts` / `lotCountsText` (`src/lib/cost-labels.ts`) для шапки источников, плитки вида и окна состава. Раньше шапка писала «300 лотов» — это 295 лотов + 3 строки заказанного (100 позиций) + 2 строки шкур подрядчика (лотов у них нет). |
| Округление денег на экране | **Сумма показанных частей = показанный итог** | Суммы считаются точно (копейки и меньше), округляются только при показе (`src/lib/money-round.ts`). Итог блока = округлённая сумма неокруглённых значений; части, которые складываются в итог (куплено = использовано + остаток, виды = всего, года = всего, мех + подкладка), выравниваются методом наибольших остатков, поэтому сумма показанных частей совпадает с показанным итогом ровно до рубля. Часть может отличаться от точной не больше чем на 1–2 ₽. Проверка: `scripts/test-rounding-rule.ts`. |
| Копейки лотов и документов | **округление (лоты и документы)** | Цена за единицу в лоте хранится округлённой, поэтому «Куплено» (сумма лотов) и «Оплачено + К оплате» (документы) расходятся на рубль-два; в плитках оплат это отдельная строка, «Общая стоимость» берётся как «Куплено». |
