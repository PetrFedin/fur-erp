# Словарь терминов (подписи на экранах)

Только то, что видит пользователь. Ключи в коде, имена полей БД и названия документов («Спец. №13», «УПД №181») не меняются.

| Термин | Как показываем | Что значит |
|---|---|---|
| Итог по таблице | **Всего, ₽** (`TotalLabel`) | Сумма строк таблицы. Единица после запятой: ₽, шт., м, ₽/шт. |
| Итог по всем видам меха | **Все виды меха** | Первый слайд плиток и каруселей по меху (бывший «Тотал»); значения по всем видам меха сразу. |
| Итог по производству | **Всего** | Первый слайд плиток «Произведено» / «Себестоимость»; включает ремонт, группы «Одежда» и «Аксессуары» дают срезы. |
| Остаток на складе | **остаток на складе** | Что куплено и ещё не списано в ТЗ (бывшее «сток»). |
| Отклонение (Var) | **Отклонение** | Бюджет к текущим ценам системы, %: красный — выше на 15%+. |
| Наценка (маркап) | **Наценка** | Цена ÷ себестоимость; в средних — взвешено по выпуску. |
| Спецификация | **спецификация** | Приложение к договору с поставщиком. В названиях документов остаётся «Спец. №13». |
| 4% | **4%** с «i»: надбавка 4% к сырью | Доп. комиссия посредника (Веллмех): +4% к цене меха и подкладки в ТЗ. К закупкам, оплатам и долгу не применяется. |
| Долг | **Долг**, **К оплате**, **Остаток** | Сумма минус оплачено, положительная. |
| Переплата | **Переплата N ₽** | Оплачено больше, чем стоит: отрицательный долг показывается положительным числом с этой подписью. Расчёт не меняется. |
| Номер ТЗ | **ТЗ 167** | Рабочий номер заказа (`workOrderNumber`). Внутренний «П-2026-0129» — мелко или в «i». |
| Внутренний номер ТЗ | **П-2026-0129** | Служебный уникальный номер позиции заказа; у нескольких позиций одного ТЗ рабочий номер общий. |
| Лоты в сводках | **5 лот.** (неразрывный пробел) | Число лотов в строке или плитке. |
| Лот | **Лот 70101** / карточка лота | Партия шкур или ткани с номером аукциона. Номер в таблицах — ссылка на карточку лота. |
| Вид меха | **Вид меха: Соболь** | Справочник видов; название вида в таблицах ведёт на страницу вида. |
| Партия (аукцион) | **SAGA 03.26** | Группа закупок одного аукциона; оплаты ведутся по партии целиком. |
| Куплено / Использовано / Остаток | **Куплено**, **Использовано**, **Остаток** | Куплено = Использовано + Остаток (без 4%). |
| С НДС / без НДС | **с НДС**, **без НДС** | Режим цен из шапки сайта. Рубль в числе один раз: «583 233 535 ₽», не «₽ ₽». |
| Оплачено | **Оплачено** | Сумма подтверждённых и неподтверждённых оплат без чужих переплат. |
| Журнал изменений | **История** | Расшифровка «поле: было → стало»; для составных и неизвестных полей — «изменено: поле», полное значение в «Подробнее». |
| Название вкладки | **<страница> — MVST FUR PRODUCTION** | Шаблон в корневом layout; у карточек в названии есть имя записи («Закупка З-2026-0049», «ТЗ 167»). |
