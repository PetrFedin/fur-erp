## 4. Математическая сверка СП/РП 03.25

Для 12 счетов:
- СП: 1046, 1048, 1049, 1050, 1051, 1052, 1053
- РП: 2153, 2154, 2155, 2156, 2157

Количество по счетам совпадает с итоговым расчётным Excel; всего 3002 шкуры.

9 из 12 счетов сходятся по выделке, перевозке и total до заданного допуска.

Три исключения:
- 1053: у лота 3751-2 (28 шкур) `costBreakdown = null`; итоговая `unitCost/totalCost` сохранена, отсутствует только детализация.
- 2157: у лота 1498-2 (12 шкур) `costBreakdown = null`; итоговая стоимость сохранена, отсутствует детализация.
- 2156: выделка, перевозка, комиссия, молоток и НДС совпадают; отличие итогового Excel составляет 39,804138 ₽ в строке услуг аукциона. Подписанный первичный документ имеет приоритет над расчётным Excel, поэтому сумму БД не корректировать только ради совпадения с Excel.

Правило приоритета для дальнейшей сверки:
1. подписанный первичный документ / УПД;
2. счёт / спецификация;
3. расчётный Excel;
4. письмо / комментарий.

## 5. Правило дальнейшей привязки

Автоматически привязывать документ только если связь подтверждается сочетанием минимум двух независимых признаков:
- номер счёта / УПД;
- дата;
- сумма;
- поставщик;
- партия / auctionSession;
- количество / состав позиций.

Совпадение только по названию файла недостаточно.
