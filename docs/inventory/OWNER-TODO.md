## 4. Оригиналы файлов
В приложении у документов Drive пока ссылки «Открыть в Drive». Чтобы хранить сами файлы:
1. Скачайте папку «мех» с Google Диска на компьютер (правый клик → «Скачать»; распакуйте архив).
2. Скажите путь к папке — файлы будут сопоставлены и загружены скриптом `scripts/attach-local-drive-files.ts`
   (пробный режим покажет «сопоставлено N из M», откат — `--rollback`).
3. Любой отдельный файл можно загрузить прямо в приложении: карточка закупки / ТЗ / партии / оплаты → «Загрузить файл» у документа.
