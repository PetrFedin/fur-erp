# Будущие разбивки плиток Главной (заготовка, в UI не выведено)

Решение владельца: пока плитки «Выпуск» и «Остаток» остаются как есть. Данные для разбивок уже считаются; добавлена чистая обвязка без вывода на экран.

## Что готово

Файл `src/lib/future-split.ts` (читает готовый `DashboardData`, ничего не пересчитывает):

| Функция | Что даёт | Откуда берёт |
|---|---|---|
| `issueSplit(d)` | «Выпуск»: завершено (`doneQty`) / в работе (`inWorkQty`) / все ТЗ (`totalQty`) | `d.prod.done.qty`, `d.prod.work.qty`, `d.prod.all.qty` (`loadDashboard`, `dashboard-data.ts`, строка с `prod: { done, work, all }`) |
| `remainderSplit(d)` | «Остаток» меха: на складе / заказано, шт. и ₽ (с НДС и без) | `d.raw.fur.{incl,excl}.remQty/remValue` и `d.ordered` (заказано, лотов ещё нет); в `fur-table.ts` такие позиции — синтетические лоты с id `ordered:<вид меха>`, они входят в «Куплено» и «Остаток» |

План/факт по ТЗ в `d.prod`: `done` — завершённые (факт выпуска), `work` — запланированные и в работе (план по `plannedQuantity`).

## Где подключить

1. Плитка «Выпуск» — `src/app/(app)/dashboard/production-block.tsx` (и полоса «Произведено» в `main-strip.tsx`): добавить строки `TileList` из `issueSplit(D)`.
2. Плитка «Остаток» — `src/app/(app)/dashboard/raw-block.tsx` (колонка «Остаток»): добавить подстроки «на складе» / «заказано» из `remainderSplit(D)`.
3. Подпись в «i» и в `docs/terms-glossary.md` — одна фраза: «Остаток = на складе + заказано».

Расчёты не менять: сумма двух частей должна совпадать с текущим числом плитки (проверка — `scripts/test-reconciliation.ts`, «проверок 375, расхождений 0»).
