# Раздел «Сырьё»: карта данных и действий (23.11.2026)

Состояние после перестройки: единая полоса итогов, витрина данных, снимки. Режимы шапки (Закупка · Год · НДС · 4 %) действуют на весь раздел.

## 1. Карта переходов (куда можно провалиться)

```
Главная (блок «Сырьё», плитки «Активы: мех», «Оплаты»)
   └─► Сырьё /lots
         ├─ вкладка «Все»        → /purchases (закупки по документам: мех · подкладка · услуги по УПД)
         ├─ вкладка «Мех»        → /lots            (полоса итогов · таблица динамики · график месяцев · сравнение аукционов)
         ├─ вкладка «Подкладка»  → /lots?tab=lining (то же, в метрах)
         └─ вкладка «Аналитика»  → /analytics/raw   (разрезы · сверка · CSV)

Мех:
  строка вида меха ──► /lots/fur/<вид>            (вид меха: полоса · таблица год→аукцион→лот · из чего складывается цена · использование по ТЗ)
  строка аукциона ─► /lots?auction=<партия>       (аукцион: полоса · счета · состав стоимости · лоты · подтверждение · оплаты · документы)
  строка счёта ────► /purchases/<id>               (закупка/счёт: итоги · позиции · состав стоимости · расходы · оплаты · документы)
  строка лота ─────► /analytics/raw/lot/<id>       (лот: итоги · паспорт · цена и расходы · где использован · поля и документы)
  строка ТЗ ───────► /production/<id>              (производство)
  «Оплаты →» ──────► /payments?auction=<партия>    (оплаты)
Подкладка:
  партия ─────────► /lots/lining/<партия>         (партия подкладки: полоса · паспорт · ткани · использование по ТЗ · документы)
Доплата подрядчику ► /lots/contractor-hides      (НДС 22 % по сырью заказчика; вне «Куплено» по решению 23.11.2026)
Аналитика:
  /analytics/raw ──► /analytics/raw/recon (сверка лотов) · CSV: таблица / по лотам
Справочники:
  материал ► /materials/<id> · «+ Добавить материал» ► /materials/new
```

Вверх: хлебные крошки на каждой странице (Главная › Сырьё › Мех › Вид › Аукцион › Лот).

## 2. Единая полоса итогов (одна на каждом уровне)

| Число | Что | Источник |
|---|---|---|
| Куплено | сумма лотов (+ «заказано, не получено»), шт./м, ₽/шт., $/шт. | витрина DmLot + DmLotBridge |
| Использовано | списано в ТЗ; при «С 4 %» с надбавкой и строкой «в т.ч. 4 %» | DmLotUse, usedCost + usedExtra |
| Остаток | на складе (+ заказано) | DmLot.remCost |
| Оплачено | оплаты по лотам/партии (с НДС) | оплаты, доли по стоимости |
| Долг | к оплате поставщику | оплаты |

Режим НДС выбирает столбец «с НДС / без НДС» без пересчёта. Режим «4 %»: «Без 4 %» — надбавка нигде не показывается.

## 4. Как упорядочены данные (уровни)

```
Лот (L0)  →  Закупка/счёт (L1)  →  Аукцион/партия (L2)  →  Вид меха / год (L3)  →  Сырьё (L4)  →  Главная (L5)
каждый уровень = сумма нижнего; сверки: «Контроль → Данные»
```

## 5. Откуда берутся числа

| Экран | Источник | Если устарело |
|---|---|---|
| /lots, вид меха, Главная (без фильтров), Cashflow (предоплата), баланс и прогноз сырья | снимки DmSnapshot (Главная по году × 4 %, лоты, виды) | расчёт вживую |
| график месяцев, аналитика сырья | DmLot / DmLotUse / DmLotBridge | расчёт вживую (RAW_FROM_MART=0) |
| аукцион, закупка, лот, партия подкладки | живые запросы (детали записей) | — |
| оплаты | оплаты и аукционы (supplier-debt) | — |

Пересборка витрины и снимков: через 90 секунд после записи (фон) или кнопка в «Контроль → Данные».

## 6. Что связано с чем (кто влияет на кого)

- Запись закупки, лота, списания, оплаты → `revalidateAll` → снимки устаревают → пересборка → числа везде одинаковые.
- Лот → закупка → партия: смена закупки лота перепривязывает его по всей цепочке.
- Цена и количество лота → состав цены, списания в ТЗ, остаток, себестоимость.
- Курс закупки → цена шкуры в ₽ → все суммы.
- Оплата аукциона → «Оплачено» и «Долг» на всех уровнях, делится по стоимости лотов.

## 7. Что не сделано / открыто

- Группировки аукцион/год/вид/лот есть и в «Сырье», и в «Аналитике» (полное слияние в один экран не сделано).
- $/шт. на аукционе и закупке не показывается (нет цены в долларах в расчёте лота).
- Таблица лотов на аукционе: колонки «Операция» и «Курс» не упрощены.
- Две закупки подкладки 07.25 (З-2026-0032 и 0060): лот записан не в ту закупку, ±607 118 ₽ — ждёт решения.
- На боевой стенд витрина и снимки не выложены (три миграции).
