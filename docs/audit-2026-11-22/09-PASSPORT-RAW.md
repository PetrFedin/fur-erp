# Паспорт раздела «Сырьё» (22.11.2026): сборка снизу вверх

Решения владельца: идём от самой глубокой детализации (лот) вверх; в каждый лот можно провалиться и увидеть все цифры и сведения; подкладка — отдельной вкладкой; цена лота всегда есть по документам вместе с количеством шкур, ценами и расходами; $/шт. нужна везде; «шкуры подрядчика» — всегда сырьё.

## 1. Принцип: каждый уровень = сумма нижнего

| Уровень | Что это | Считается как | Проверка сходимости |
|---|---|---|---|
| **L0 Лот** | позиция документа: N шкур одного вида/цвета по одной цене | из документа (УПД, счёт) + расходы лота | лот.сумма = количество × цена шкуры |
| **L1 Закупка** | один документ-закупка | Σ лотов (+ расходы закупки по статьям) | Σ лотов = «Итого по расчёту» закупки |
| **L2 Партия / аукцион** | группа закупок («СП 03.25») | Σ закупок | Σ закупок = итог партии; оплаты партии |
| **L3 Вид меха / год** | срез по виду (Соболь) и году закупки | Σ лотов вида | Σ видов = итог сырья |
| **L4 Сырьё (мех)** | весь мех = лоты + шкуры подрядчика | Σ видов | Куплено = Использовано + Остаток |
| **L5 Главная** | блоки «Активы: мех», «Сырьё» | берут L4 как есть, без пересчёта | число на Главной = число L4 |

Навигация в обе стороны: вниз из любой строки (вид → партия → закупка → лот → ТЗ/документ/платёж); вверх хлебными крошками «Лот → Закупка → Партия → Вид → Сырьё → Главная». Стрелка «глубже» рисуется только там, где ниже есть содержимое.

Все числа берутся из витрины (`DmLot`, `DmPurchase`, `DmLotUse`, `DmPayment*`), экраны их не пересчитывают.

## 2. L0 — карточка лота (атом, всё детально)

Источник сейчас: `/analytics/raw/lot/[id]`. Содержание:
1. **Паспорт:** № лота, вид меха, цвет, сорт/описание, дата, поставщик, закупка (ссылка), партия/аукцион (ссылка), документ (счёт №, УПД №, дата), ставка НДС и её основание (по дате документа).
2. **Количество:** получено шкур, использовано, остаток; куплено до/после даты.
3. **Цена лота по документам:** цена шкуры без НДС / НДС / с НДС; молоток ₽ и $ (и курс); сумма лота; в $ и в ₽ везде.
4. **Расходы лота по статьям** (на шкуру и всего): сырьё (молоток), валютные комиссии, транспорт и таможня, выделка, выкраска, аукционные сборы и брокер, комиссия Веллмех, прочее. Значения показываются всегда, категория — подпись строки (а не пустой выпадающий список в каждой строке).
5. **Движение:** таблица ТЗ-потребителей (ТЗ, артикул, шкур, сумма без 4 % / с 4 %, дата), остаток.
6. **Оплата:** доля оплаты лота через закупку и партию (оплачено, долг), ссылки на платежи.
7. **Документы:** счёт, УПД, платёжка.
8. **Действия:** правка полей по месту (получено, цена, цвет, привязка к закупке).
9. **Вверх:** Закупка → Партия → Вид меха → Сырьё.

## 3. L1 — карточка закупки (`/purchases/[id]`)
Шапка: дата, поставщик, партия, счёт, УПД, НДС. Итоги: всего с НДС, оплачено, остаток. Секции: **Позиции** (= лоты: материал, лот, сорт/цвет, количество, цена без НДС, НДС, сумма) → **Состав стоимости** (по статьям расчёта в $ и ₽) → **Цена единицы по лотам** → **Расходы** → **Оплаты** → **Документы**. Каждая позиция ведёт в карточку лота. Предупреждение «подтверждена, но менялась» остаётся (ловится «Контролем»).

## 4. L2 — партия/аукцион (`/lots?auction=…`)
Закупки партии (таблица), итоги, оплаты партии (оплачено/долг/переплата), документы партии, лоты списком. Ведёт в закупки и в «Оплаты».

## 5. L3–L4 — «Сырьё» (мех): один экран, одно дерево
- **Полоса итогов (4 числа):** Куплено · Использовано · Остаток · К оплате; в каждом шт., ₽, ₽/шт., **$/шт.**
- **Одна таблица-дерево** вместо карусели из 6 комплектов плиток и двух таблиц динамики. Группировка переключается: **по виду меха / по году / по аукциону / списком лотов**. Строки раскрываются вниз: вид → партия → закупка → лот; лот ведёт в карточку.
- Столбцы одинаковые на всех уровнях: куплено (шт., ₽, ₽/шт., $/шт.), использовано, остаток, оплачено, долг.
- **«Шкуры подрядчика»** — строка внутри «Сырья» (источник «Подрядчик»), входит в «Куплено» (229 150 ₽); её дно — страница `/lots/contractor-hides` (ТЗ-доли и оплаты). Тогда «Куплено» = 582 520 179 ₽ совпадает с закупками и «Общей стоимостью» (сейчас на `/lots` плитка 582 291 028).
- **Фильтры:** источник закупки (вся / на аукционах / у поставщика), аукцион/партия, вид, цвет, остаток, поиск.
- **Режимы шапки:** НДС, «4 %», год — на месте всегда (решение владельца).
- **Главная кнопка:** «+ Закупка меха» (мастер). Вторичные: «+ Подкладка», экспорт. «Материал» уходит в «Настройки».

## 6. «Подкладка» — отдельная вкладка той же структуры
Те же уровни (лот → закупка → партия → вся подкладка), единицы — метры, ссылки на `/lots/lining/[партия]`. Отдельная вкладка рядом с «Мех».

## 8. Что нужно в данных (витрина)
1. `DmLot`: добавить молоток $/₽ и курс, расходы лота по статьям, ссылки на позицию, счёт и УПД документа.
2. Шкуры подрядчика — как строки сырья (псевдо-лоты «Подрядчик»).
3. Оплаты по аукциону целиком и `confirmedAt` в `DmPayment`; валюта и курс платежа.
4. Сверки «Σ нижнего = верхнему» на каждом уровне (в «Контроль → Данные»): лоты по закупке, закупки по партии, виды по сырью, сырьё на Главной.
5. Пересборка после записи (уже в фоне через 90 с).
6. Вынести из кода: счета Веллмех (`supplier-debt.ts:42-47`), год 2026.
